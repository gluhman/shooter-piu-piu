# Tactical operator

[Military tactical suit (LowPolyGameReady)](https://sketchfab.com/3d-models/military-tactical-suit-lowpolygameready-ef698ce36b1545a78ce592dd3db4c7ed) by DanlyVostok (1799danly), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The Godot project uses the [glTF edition from 3d-fps](https://github.com/cktang88/3d-fps/blob/main/public/assets/models/characters/soldier_tac.glb), which packs the textures as WebP. The game supplies its own pose, controls local visibility, and omits the misplaced headset.

The 2K uniform, vest and pouch maps preserve the original UV layout and use woven detail from [Fabric 030](https://ambientcg.com/view?id=Fabric030) by ambientCG, [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The blue and red team albedos are 2K color variants of the operator textures above. Both keep the original UVs, rig and fabric normal maps.

Poly Haven CC0 additions:

- [Fabric Pattern 05](https://polyhaven.com/a/fabric_pattern_05) by Rob Tuytel. The weave normal was blended into the existing UV-aligned suit, vest, and pouch normals. Roughness maps were derived from the green channel of the packed ARM texture. All camouflage and team colors still use the existing albedos.
- [Fabric Leather 02](https://polyhaven.com/a/fabric_leather_02) by Rob Tuytel. Normal and roughness detail for the protective pads.
- [Digital Wrist Watch](https://polyhaven.com/a/digital_wrist_watch) by Adrian C. The watch case is fitted to the left cuff of the existing skeleton.
