# Classic Weapons Pack

Source: [Free Classic Weapons Pack by Stein Games](https://stein-indie.itch.io/classic-weapons-pack), CC0 1.0. The original license is in LICENSE.txt.

The seven FBX files and their textures come from Classic Weapons Pack v1.1. The existing AK-47 model from the same pack is in assets/ak47.

The original audio.zip is preserved in source_audio. The game uses sets of firing variations, assembled reload cues and two action sounds from the archive.

| Weapon | Firing | Reload and action |
|---|---|---|
| AK-47 | AK-47 | AK-102 |
| M1911 | USP | USP and 1911 hammer |
| MAC-10 | UMP | UMP |
| MP5 | MP5 | MP5 |
| M700 | 7.62 close reports | M14 handling |
| TEC-9 | M9 | M9 |
| Lever Action | .357 body reports | .357 reload and action |
| M14 | M14 | M14 |
