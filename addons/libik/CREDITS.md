# GodotIK

Author: monxa. MIT license; see LICENSE.md.
Pinned release: [v1.3.1](https://github.com/monxa/GodotIK/releases/tag/v1.3.1).
Source: https://github.com/monxa/GodotIK
Archive: godot-libik-plugin-v1.3.1.zip, copied without replacing an existing installation.

Used for the player's two upper-arm/forearm/hand FABRIK chains. Effectors use
FULL_TRANSFORM, explicit bone indices and elbow pole constraints. The custom body,
locomotion and finger modifier executes first; final-pose consumers update after
GodotIK. The package includes desktop, mobile and web binaries supplied upstream.
The macOS library contains both arm64 and x86_64 slices.

Suggested by the discussion:
https://godotforums.org/d/43019-full-body-fps-player-rig-control-over-arms-issues
