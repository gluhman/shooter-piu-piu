# SpatialAudio3D

[SpatialAudio3D от Claude Hohl](https://github.com/claudehohl/SpatialAudio3D), ревизия `d031fa7c5afe7803cb5d7f266e27c61f89419f74`, [MIT](LICENSE).

Шаги других бойцов используют задержку по расстоянию и приглушение за стенами. Для выстрелов других бойцов выделено четыре переиспользуемых источника с двумя отражениями на источник. Если все четыре заняты, дополнительные выстрелы воспроизводятся обычным позиционным звуком. Акустические лучи учитывают слой геометрии арены.
