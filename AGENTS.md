# Инструкции для агентов

## Godot MCP

В проекте настроены два локальных MCP-сервера. Используй их для задач, которым нужен редактор Godot, запуск игры, диагностика GDScript, исследование сцен или playtest.

| Сервер | Когда использовать |
| --- | --- |
| `godot-mcp-toolkit` | Основной инструмент для открытого редактора: сцены, узлы, GDScript, ресурсы, диагностика и playtest. |
| `godot-cli` | Запуск редактора и проекта, вывод отладки, версия Godot и базовый анализ проекта. |

- Перед `godot-mcp-toolkit` открой этот проект в Godot. Рабочий путь — корень с `project.godot`.
- Для изменений сцен и ресурсов предпочитай Toolkit: его операции входят в Undo-историю редактора. Для небольших текстовых правок GDScript допускается штатный редактор файлов.
- Сначала используй read-only инструменты: прочитай сцену, диагностику или лог. Мутирующие вызовы выполняй только когда они нужны задаче и после проверки целей.
- Не вызывай `execute_code`, удаление файлов/узлов и изменение настроек проекта без явной необходимости. Не передавай в инструменты секреты, сессионные токены и содержимое `user://`.
- Для безопасного исследования запускай клиент с `GODOT_MCP_READ_ONLY=1`.
- После изменения GDScript проверяй встроенную диагностику Toolkit или запускай релевантный тест. После изменения интерфейса/сцены проверяй итоговое состояние в playtest, а не только успешность вызова.
- Если Toolkit недоступен, проверь, что редактор открыт и в Output есть сообщение `[MCPServer] listening`. Если `godot-cli` не находит движок, проверь путь `/Applications/Godot.app/Contents/MacOS/Godot`.
- MCP-конфигурации закреплены в `.mcp.json` и `.codex/config.toml`. При обновлении меняй версии в обоих файлах одновременно; не заменяй аддон поверх существующей версии — сначала удали старый `addons/godot_mcp_toolkit/`.
- Конфигурация MCP читается при создании сессии. После её изменения перезапусти локальный MCP-клиент или начни новую сессию.

Подробная инструкция и проверенные версии — в [docs/mcp.md](docs/mcp.md).
