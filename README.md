# shooter-piu-piu

Дедматч от первого лица во дворе из контейнеров. Можно играть одному против 1–10 ботов или по локальной сети в комнате до 10 игроков, включая хоста.

Движок: Godot 4.7.

## Запуск

1. Установи [Godot 4.7](https://godotengine.org/) без .NET.
2. Открой эту папку как проект.
3. Нажми F5.

В главном меню:

- **Играть одному** — выбери карту, набор оружия, число ботов и сложность.
- **Создать игру** — открой сетевую комнату и передай другу IP из комнаты.
- **Подключиться** — друг вводит этот IP. Порт 7777, его вводить не нужно.

Все игроки должны быть в одной локальной сети. В комнате виден статус подключения каждого игрока. Хост выбирает карту и набор оружия и запускает матч. После запуска каждый выбирает оружие из заданного набора.

Камера расположена на уровне глаз бойца, горизонтальный угол обзора — 110°. В сетевой игре видно оружие и перезарядку других игроков. В меню матча можно начать раунд заново. В сетевой игре это делает хост. Настройки управления и графики сохраняются между запусками. [Модель бойца и лицензия](assets/operator/CREDITS.md).

## Управление

| Клавиша | Действие |
| --- | --- |
| W A S D | ходьба |
| Alt | бег |
| Левый Shift (удерживать) | присесть |
| Пробел | прыжок |
| ЛКМ | выстрел |
| ПКМ или левый Ctrl (удерживать) | прицеливание через мушку с приближением |
| R | перезарядка |
| Enter | открыть ящик или подобрать предмет |
| 1 / 2 / 3 | выбрать пистолет, дробовик или автомат |
| H | использовать аптечку при неполном здоровье |
| Esc | открыть меню матча |
| Tab | показать таблицу счёта |

## Оружие

- **Desert Eagle** — одиночные, 52 урона вблизи, 7 патронов в магазине.
- **Дробовик** — картечь 14×8, 6 патронов в магазине. При перезарядке патроны вставляются по одному.
- **AK-47** — автоматический огонь при удержании ЛКМ, 24 урона вблизи, 30 патронов в магазине. [Модель, текстура и звуки](assets/ak47/CREDITS.md).

У всех по 100 здоровья. Счёт убийств и смертей сверху.

## Припасы

Военные ящики появляются в укрытых местах и внутри проходных контейнеров. Их расположение меняется при загрузке карты. Каждый ящик даёт случайную награду — оружие из набора матча, патроны для текущего оружия или аптечку на 45 HP.

Инвентарь хранит собранное оружие, патроны каждого типа и аптечки. При смене оружия патроны остаются в его магазине. После гибели тело и припасы лежат на карте 60 секунд. При возрождении игрок получает стартовое оружие, а бот — случайное оружие из набора матча.

[Авторы моделей ящика, травы и кустов](assets/arena_props/CREDITS.md).

## Что внутри

Выбранная карта собирается при запуске матча. Хост определяет попадания и управляет ботом в сетевом матче. Снаряды летят от дула с учётом скорости игрока, гравитации и сопротивления. Перекрестие показывает ожидаемую точку попадания по центру разброса, в том числе при стрельбе от бедра. У пистолета и автомата летит одна пуля, у дробовика — восемь отдельных дробин. Параметры полёта настроены под размеры игровой карты.

Пуля AK-47 может пробить одну тонкую стенку контейнера, потерять энергию и изменить направление. Пистолетные пули и дробь рикошетят от стали при попадании под скользящим углом. Лёгкие деревянные ящики пропускают пули пистолета и автомата, а дробь в них останавливается.
