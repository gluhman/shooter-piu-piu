# shooter-piu-piu

Дедматч от первого лица во дворе из контейнеров. Можно играть одному против бота или вдвоём по локальной сети.

Движок: Godot 4.7.

## Запуск

1. Установи [Godot 4.7](https://godotengine.org/) без .NET.
2. Открой эту папку как проект.
3. Нажми F5.

На старте три кнопки:

- **Играть одному** — ты и бот.
- **Создать игру** — ты хост. Внизу экрана появится твой IP, его нужно сказать другу.
- **Подключиться** — друг вводит этот IP. Порт 7777, его вводить не нужно.

Оба игрока должны быть в одной сети Wi-Fi. После входа каждый выбирает оружие.

Камера расположена на уровне глаз бойца, горизонтальный угол обзора — 110°. В сетевой игре видно, как второй игрок держит оружие и перезаряжается. В меню матча можно начать раунд заново. В сетевой игре это делает хост. Настройки управления и графики сохраняются между запусками. [Модель бойца и лицензия](assets/operator/CREDITS.md).

## Управление

| Клавиша | Действие |
| --- | --- |
| W A S D | ходьба |
| Alt | бег |
| Левый Shift (удерживать) | присесть |
| Пробел | прыжок |
| ЛКМ | выстрел |
| ПКМ или левый Ctrl (удерживать) | прицеливание через мушку с приближением |
| R | перезарядка |
| 1 / 2 / 3 | выбор оружия в меню |
| Esc | открыть меню матча |
| Tab | показать таблицу счёта |

## Оружие

- **Desert Eagle** — одиночные, 52 урона вблизи, 7 патронов в магазине.
- **Дробовик** — картечь 14×8, 6 патронов в магазине. При перезарядке патроны вставляются по одному.
- **AK-47** — автоматический огонь при удержании ЛКМ, 24 урона вблизи, 30 патронов в магазине. [Модель, текстура и звуки](assets/ak47/CREDITS.md).

У всех по 100 здоровья. Счёт убийств и смертей сверху.

## Что внутри

Карта собирается при запуске. Игрок, бот, полоски здоровья, звуки дробовика и сетевой матч на два человека уже в проекте. Хост решает попадания и ведёт бота. Снаряды летят от дула с учётом скорости игрока, гравитации и сопротивления. Перекрестие показывает ожидаемую точку попадания по центру разброса, в том числе при стрельбе от бедра. У пистолета и автомата летит одна пуля, у дробовика — восемь отдельных дробин. Параметры полёта настроены под размеры игровой карты.
