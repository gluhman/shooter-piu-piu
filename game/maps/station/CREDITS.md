# Ресурсы «Станции»

- Лунный рельеф за обзорными окнами построен модулями карты высот и сетки [GDT Terrain Generator 1.1.0](https://godotengine.org/asset-library/asset/5160). В проекте используется [ревизия из Godot Asset Library](https://github.com/wondrkid00/GDT-Terrain-Generator/tree/bd531b00cd7e6f047bc0e8ffe2fbdc0ac59904f1) с [лицензией MIT](../forest_ridge/art/gdt/LICENSE).
- [Qwantani Night (Pure Sky)](https://polyhaven.com/a/qwantani_night_puresky), [Metal Plate](https://polyhaven.com/a/metal_plate) и [Blue Metal Plate](https://polyhaven.com/a/blue_metal_plate) взяты с Poly Haven в разрешении 2K. Для поверхности за окнами используется [Rocky Terrain 02](https://polyhaven.com/a/rocky_terrain_02) из «Форпоста».
- Модели с текстурами 2K взяты с Poly Haven по [лицензии CC0](https://polyhaven.com/license). [Modular Airduct Rectangular 01](https://polyhaven.com/a/modular_airduct_rectangular_01), [Industrial Caged Sconce](https://polyhaven.com/a/industrial_caged_sconce), [Metal Tool Chest](https://polyhaven.com/a/metal_tool_chest), [Power Box 01](https://polyhaven.com/a/power_box_01).
- Звуки шагов нарезаны из пользовательских MP3, опубликованных под [Pixabay Content License](https://pixabay.com/service/license-summary/). [Footsteps on Metal Floor — nate_asdfg (Freesound)](https://pixabay.com/sound-effects/household-footsteps-on-metal-floor-45788/) и [Footsteps on stairs_01 — 121053699 (Freesound)](https://pixabay.com/sound-effects/film-special-effects-footsteps-on-stairs-01-98640/).
- Цветные светильники и локальные источники подсветки для ночной сцены основаны на подходе из [урока SeasonalAsh по освещению в Godot](https://www.youtube.com/watch?v=X112OrjzWKQ&t=865s).
