# MCP-интеграции Godot

В проекте подключены два дополняющих локальных MCP-сервера. Они предназначены для разработки и не входят в экспорт игры.

| Сервер | Роль | Версия |
| --- | --- | --- |
| `godot-mcp-toolkit` | Связь с открытым редактором: сцены, GDScript, ресурсы, playtest и диагностика | Toolkit и bridge `1.1.2` |
| `godot-cli` | Запуск редактора и проекта, вывод отладки, базовый анализ проекта | `@coding-solo/godot-mcp` `0.1.1` |

## Требования

- Godot 4.7.2 stable в `/Applications/Godot.app`;
- Node.js 22 или новее;
- запуск MCP-клиента из корня проекта.

## Настройка

`addons/godot_mcp_toolkit/` добавлен в репозиторий и включён в `project.godot`. После первого открытия проекта в Godot проверьте, что в нижней панели появился **MCP** и в Output есть сообщение о прослушивании `127.0.0.1`.

`.mcp.json` содержит конфигурацию для совместимых MCP-клиентов. Для Codex используется также проектный `.codex/config.toml`; его конфигурация действует только для доверенного проекта. Оба файла закрепляют версии пакетов, чтобы следующий запуск не получил несовместимое обновление через `npx`, и включают маркер схемы Toolkit `GODOT_MCP_CONFIG_VERSION=1`.

Toolkit открывает только localhost и использует сессионный токен, который создаётся локально. Он не должен попадать в Git, логи или чат. Для безопасного исследования установите перед запуском MCP-клиента `GODOT_MCP_READ_ONLY=1`: mutating-инструменты Toolkit тогда скрываются.

## Проверка

1. Откройте проект в Godot. Редактор активирует `Godot MCP Toolkit` автоматически.
2. Перезапустите Codex или начните новую сессию из корня проекта, чтобы он перечитал конфигурацию MCP. Уже открытая сессия не получает новые инструменты автоматически.
3. Выполните безопасный запрос: перечислить сцены проекта или показать версию Godot. Для Toolkit сначала должен быть открыт редактор; для `godot-cli` достаточно установленного бинарного файла.

Если Godot находится в другом месте, измените `GODOT_PATH` одинаково в `.mcp.json` и `.codex/config.toml`. Не включайте `DEBUG=true` в постоянную конфигурацию: это добавляет избыточный вывод сервера.

## Обновление

Версии обновляются намеренно, одновременно в `.mcp.json` и `.codex/config.toml`. Перед обновлением Toolkit изучите его release notes, затем замените весь каталог `addons/godot_mcp_toolkit/` содержимым новой официальной поставки. Не устанавливайте новую версию поверх старой: в аддоне могут остаться удалённые файлы и `.uid`-сайдкары.
